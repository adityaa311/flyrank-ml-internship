Refresh / Content Opportunity Scoring

FlyRank Machine Learning Internship Capstone

Author: Aditya Dabhade

Repository: github.com/adityaa311/flyrank-ml-internship

Abstract

This project investigates whether search performance data can identify content pages that are likely to experience declining organic visibility. Using the FlyRank ML Internship dataset, DuckDB SQL was used to engineer historical performance features while query-level statistics were added to improve prediction quality. A Random Forest classifier was trained to identify pages likely to decline. The resulting model generates ranked recommendations that help SEO teams decide which pages should be refreshed first.

Problem Statement

The objective is to predict which content pages are likely to lose organic search visibility before significant traffic declines occur. The model produces ranked recommendations that help editors prioritize content refresh activities.

Dataset

  • FlyRank ML Internship Warehouse Dataset
  • DuckDB over Parquet files
  • Google Search Console daily performance
  • Query-level aggregated features

Model

Algorithm

  • Random Forest Classifier

Features

  • Previous 90-day impressions
  • Previous 90-day clicks
  • Average Position
  • Visible Query Count
  • Rare Query Share
  • Anonymous Query Share
  • Top Query Share
  • Click Through Rate

Evaluation

Metric Value
Baseline Accuracy 81%
Model Accuracy 89%
Precision 0.90
Recall 0.87
F1 Score 0.88

Recommendations

  1. Refresh pages with declining impressions.
  2. Improve metadata for pages with low CTR.
  3. Expand content targeting additional queries.
  4. Monitor pages dependent on a single search query.
