Abstract

This project investigates whether search performance data can identify content pages that are likely to experience declining organic visibility. The analysis uses the FlyRank ML Internship dataset containing pseudonymized Google Search Console performance metrics together with query-level search information. Features were engineered using DuckDB SQL before training a Random Forest classifier. The model learns relationships between historical impressions, clicks, query diversity and search behavior to identify declining content. The final output is a ranked list of pages that should be refreshed by SEO teams.

Problem Statement

The objective is to identify content pages beginning to lose search visibility before significant traffic declines occur. The model generates ranked recommendations that help editors prioritize which pages should be refreshed first.

Dataset

  • FlyRank ML Internship Warehouse Dataset
  • dim_clients
  • fact_content_daily_performance
  • fact_content_query_90d
  • Pseudonymized client information only
  • No URLs, client names or private search queries were used.

Methodology

  • DuckDB SQL feature engineering
  • 90-day historical momentum features
  • Query-level feature aggregation
  • Random Forest Classification
  • GroupShuffleSplit validation by client

Features Used

  • Previous 90-day impressions
  • Previous 90-day clicks
  • Average Position
  • Visible Query Count
  • Rare Impression Share
  • Anonymous Impression Share
  • Top Query Share
  • Click Through Rate

Results

Metric Value
Baseline Accuracy 81%
Model Accuracy 89%
Precision 0.90
Recall 0.87
F1 Score 0.88

Interpretation

Historical impressions were the strongest predictor of future decline. Pages attracting traffic from many different search queries generally remained more stable. Pages relying heavily on a single query showed higher risk of declining visibility.

Recommendations

  1. Refresh pages with declining impressions.
  2. Improve metadata for pages with low CTR.
  3. Expand content targeting additional search queries.
  4. Monitor pages relying on one dominant query.
